# Протокол проверки

Дата: 3 октября 2026 года. Проверка выполнена на Windows с Docker Desktop, Linux-контейнером Python 3.13, OpenCV 4.12.0.88 и FFmpeg 7.1.5. Compose ограничивал контейнер двумя ядрами и 2 ГБ памяти.

## Автоматические тесты

Итог: **28 passed**, без предупреждений. Команды воспроизведения приведены в README. Тесты не требуют исходных видео или доступа к внешнему API: небольшой ролик со звуком создаётся через FFmpeg внутри контейнера.

Проверены:

- IoU, однозначное связывание обнаружений, удержание короткого пропуска и завершение зоны;
- включение/выключение и исправление автоматических зон;
- интервалы и линейная интерполяция ручных зон;
- снижение локальной детализации, изменение силы размытия, обрезка по границам, сохранение пикселей вне зон до кодирования и независимость результата от порядка пересечений;
- недопустимые координаты, NaN, повторные ключевые времена, неизвестные зоны и интервалы за пределами видео;
- загрузка, полный анализ, реальный JPEG-предпросмотр, H.264-экспорт, повторный экспорт и удаление записи;
- число кадров и длительность результата, наличие звука и совпадение SHA-256 извлечённых AAC-данных между нормализованным видео и экспортом;
- HTTP Range для воспроизведения и имя скачиваемого файла;
- пустой/неверный файл, повреждённое видео, неизвестная запись, блокировка действий во время обработки;
- ограничение тела запроса, включая потоковую передачу без доверия к Content-Length;
- запрет изменений с постороннего Origin;
- поворот 90° из display metadata и корректное отображение видео с непрямоугольными пикселями;
- состояния прерванного анализа и восстановления прерванного экспорта.

Тестовый клиент — штатный FastAPI/Starlette TestClient с поддерживаемым `httpx2`; `pytest` и его зависимости устанавливаются только в тестовую стадию Docker.

## Проверка интерфейса

В браузере проверены загрузка через выбор файла, отображение этапов, выбор ранее загруженного видео, покадровая навигация, изменение силы размытия, числовая правка и сброс автоматической зоны. Ручная зона нарисована для частично обрезанного лица слева в ролике с аудиторией; проверены её координаты, временной интервал, второй опорный кадр, экспорт и скачивание.

Проверены готовый видеоплеер и адаптивная компоновка на узком экране. Обработанный кадр вычисляется сервером, а рамки редактора лишь обозначают геометрию масок. После изменения настроек старое скачивание скрывается до пересохранения.

Для самостоятельной проверки интерфейса:

1. Загрузите ролик с аудиторией; выберите автоматическую зону и измените её ширину, затем сбросьте исправление.
2. Выключите отображение размытия и сравните с исходным кадром; снова включите.
3. Добавьте ручную зону у левого края. Измените координаты и размеры числовыми полями.
4. Перейдите к концу ролика, добавьте опорный кадр и переместите зону. В середине проверьте плавное промежуточное положение.
5. Задайте интервал, сформируйте видео, просмотрите и скачайте его.
6. Измените силу размытия: приложение должно предложить пересохранить видео перед новым скачиванием.

## Найденные проблемы и исправления

- Прямой GaussianBlur с большим ядром был медленным. Введено уменьшение зоны с усреднением перед фильтром; повторный экспорт проверен на всех трёх видео.
- Числовой редактор недостаточно надёжно обновлялся при вводе. Изменения теперь учитываются непосредственно при вводе, а активное поле не перезаписывается форматированием.
- При сокращении интервала движущейся зоны могла теряться начальная позиция. На новых границах сохраняются интерполированные позиции.
- Обновление списка видео заменяло кнопки и могло терять клавиатурный фокус. Существующие строки теперь обновляются на месте.
- Исправлено восстановление настроек автоматических зон, если API экспорта использовался без явного списка зон.
- Устаревший тестовый транспорт заменён поддерживаемым; предупреждение Starlette устранено.

## Ограничения доказательств

Просмотрены контрольные кадры в начале, середине и конце каждого результата, а весь поток проверен на успешное декодирование. **Не выполнена ручная покадровая разметка каждого реального лица.** Датасет не содержит такой разметки, поэтому числовые precision/recall и утверждение «найдены все реальные лица» не приводятся.

На контрольных кадрах найден явный пропуск частично обрезанного лица у левого края аудитории. Проверено его закрытие ручной зоной. Для остальных сложных случаев также следует использовать редактор. Ручная проверка результата перед сдачей нужна, даже когда программа успешно обработала все кадры.
