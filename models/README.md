# Модель YuNet

`yunet.onnx` — файл `face_detection_yunet_2023mar.onnx` из официального OpenCV Zoo. Используется с закреплённой версией `opencv-python-headless==4.12.0.88`; модель не обучалась в этом проекте.

- Репозиторий: https://github.com/opencv/opencv_zoo/tree/47534e27c9851bb1128ccc0102f1145e27f23f98/models/face_detection_yunet

- Скачать исходный файл: https://media.githubusercontent.com/media/opencv/opencv_zoo/47534e27c9851bb1128ccc0102f1145e27f23f98/models/face_detection_yunet/face_detection_yunet_2023mar.onnx

- Лицензия этого каталога модели: MIT, Shiqi Yu. Полный текст сохранён в `LICENSE`.

Приложение проверяет контрольную сумму перед использованием модели. Она включена в архив и образ: скачивание модели при каждом запуске не требуется. Новую динамическую модель для OpenCV 5 нельзя подменять без проверки совместимости и повторного тестирования.
