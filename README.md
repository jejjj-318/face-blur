# Face Blur — размытие лиц в видео

Учебный проект, тема 6. Веб-приложение загружает видео, находит лица в каждом кадре, позволяет исправить зоны и создаёт MP4 с размытием. Обработка выполняется локально на процессоре, без облачных сервисов.

## Запуск

Нужен запущенный Docker Desktop с Linux-контейнерами и Docker Compose. Распакуйте архив, откройте терминал **в папке `face-blur`**, рядом с `compose.yaml`, и выполните:

```console
docker compose up --build -d
```

Откройте **http://127.0.0.1:8002/**. Первый запуск скачивает зависимости; обработка затем не требует интернета. Статус контейнера:

```console
docker compose ps
docker compose logs --tail 30
```

Остановка с сохранением загруженных видео:

```console
docker compose down
```

`index.html` отдельно открывать не нужно: интерфейс работает вместе с сервером. Порт 8002 выбран, чтобы не мешать предыдущему проекту на 8000. При занятом порте измените левое число в `127.0.0.1:8002:8000` в Compose.

## Использование

1. Нажмите **«Выбрать видео»** и дождитесь подготовки и поиска лиц. Поддерживаются MP4, MOV, MKV, WebM до 250 МБ, 10 минут, 60 кадров/с и входного разрешения до 4096 × 2160 либо эквивалентного портретного кадра.
2. Выберите степень размытия. Перемещайтесь по времени ползунком или кнопками на один кадр. Предпросмотр показывает настоящее размытие, рассчитанное сервером.
3. Выберите автоматическую зону и переместите/растяните её либо задайте координаты в процентах. Исправление действует на всю траекторию этой зоны. Ненужную зону можно выключить; «Сбросить исправление» возвращает её исходную геометрию.
4. Для пропущенного лица нажмите **«Добавить»** и выделите прямоугольник на кадре. Изначально ручная зона действует на всё видео. Задайте начало и конец, если она нужна только на части ролика.
5. Неподвижная ручная зона имеет один опорный кадр. Чтобы она двигалась, перейдите на другое время, нажмите **«Опорный кадр здесь»** и исправьте её положение. Между опорными кадрами координаты и размеры меняются плавно. Вне них сохраняется ближайшая позиция в пределах интервала зоны.
6. Нажмите **«Сформировать видео»**, посмотрите готовый ролик и скачайте MP4. После изменения настроек приложение предлагает сформировать результат заново.

Флажок «Показывать размытие» переключает обработанный и исходный кадр. Раскрывающийся блок позволяет посмотреть исходное видео целиком. Несохранённые изменения редактора хранятся в браузере; настройки последнего экспорта также сохраняются на сервере.

Исходники и результаты находятся в отдельном Docker-томе `videos`. Перезапуск не удаляет завершённые записи. Прерванный экспорт можно повторить; при прерванном анализе требуется загрузить видео заново. Удаление записи из списка удаляет её файлы из тома.

## Проверка

Тесты — обычные `pytest`: геометрия масок, интервалы, связывание зон, API и полный экспорт синтетического видео со звуком. Тестовый образ отделён от основного:

```console
docker build --target test -t face-blur-test .
docker run --rm face-blur-test
```

Протокол проверки трёх предоставленных роликов и ограничения проверки: [docs/VALIDATION.md](docs/VALIDATION.md). Теоретическая база, формулы, обоснование решений и ограничения: [docs/DEFENSE.md](docs/DEFENSE.md).

## Состав проекта

| Файл / папка | Назначение |
| --- | --- |
| `app/main.py` | HTTP API, загрузка, предпросмотр и выдача файлов |
| `app/jobs.py` | Последовательная фоновая обработка, состояние и хранение записей |
| `app/video.py` | FFmpeg, YuNet, анализ и экспорт кадров |
| `app/masks.py` | Проверка параметров, геометрия, интерполяция и размытие |
| `app/static/index.html` | Структура веб-интерфейса |
| `app/static/style.css` | Оформление и адаптивная компоновка |
| `app/static/app.js` | Загрузка, редактор зон и взаимодействие с API |
| `models/` | Модель YuNet, её лицензия и происхождение |
| `tests/` | Автоматические проверки; не включаются в рабочий образ |
| `docs/` | Материалы для защиты и воспроизводимой проверки |
| `Dockerfile`, `compose.yaml` | Сборка и запуск приложения |
| `requirements*.txt`, `constraints.txt` | Версии рабочих и тестовых зависимостей |
| `.gitignore`, `.dockerignore` | Исключение данных, кэшей и лишних файлов |

В архив для Git включены только исходный код, модель с лицензией, настройки сборки, тесты и пользовательская документация. Три исходных видео, обработанные ролики, локальные проверочные скрипты, логи и кэши в него не входят. Видео выбираются с устройства через интерфейс; класть их в репозиторий не требуется.

Стек: Python 3.13, FastAPI, OpenCV 4.12 / YuNet, NumPy, FFmpeg; HTML, CSS, JavaScript без сборщика. Основной контейнер работает от непривилегированного пользователя, слушает только локальный порт компьютера, использует до 2 ГБ памяти и 2 процессорных ядер.

Автоматическое обнаружение может пропустить лицо, особенно при перекрытии, сильном повороте, малом размере или обрезании краем кадра. Проверяйте результат и добавляйте ручные зоны. Этот проект реализует визуальное размытие и не доказывает необратимость обезличивания.
